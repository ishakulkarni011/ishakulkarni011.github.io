# Isha Kulkarni – Portfolio Website

## Overview
This is a personal portfolio website for **Isha Kulkarni**, showcasing professional experience, academic background, technical skills, and projects. The website serves as a comprehensive digital resume and professional portfolio.

## Features
- **Professional Profile:** Overview of background, interests, and career focus  
- **Project Showcase:** Highlighted projects with concise descriptions and technologies used  
- **Experience Timeline:** Chronological display of professional experience with expandable details  
- **Skills Section:** Organized presentation of technical skills and tools  
- **Education:** Academic qualifications and institutions  
- **Contact Information:** Multiple ways to connect professionally, including a contact form

## Technologies Used
- **HTML5**
- **CSS3**
- **JavaScript**
- **Tailwind CSS** (via CDN)
- **Font Awesome** (icons)
- **GitHub Pages** (for hosting)

## Deployment
The website can be deployed using **GitHub Pages** from the `main` branch of this repository.
